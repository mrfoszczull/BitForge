# BitForge

BitForge is a C17 library for binary data manipulation and analysis.

## Features

- Bit-level operations on bytes
- Status codes for error handling
- Binary file manipulation *(planned)*

## Requirements

- C compiler with C17 support
- CMake 3.20 or newer

## Build

```bash
cmake -S . -B build
cmake --build build
```

## Project Status

BitForge is currently under development.
